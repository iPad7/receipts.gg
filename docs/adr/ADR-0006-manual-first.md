# receipts.gg (가제) — ADR-0006 — 수동 RMS 우선, 외부 연동은 어댑터로 추가

- 개정: 2026-10-13 / 문서 패키지 v0.3 (참조 절 보정)
- 날짜: 2026-10-13
- 상태: Proposed
- 참조: PRD.md, SOFTWARE_ARCHITECTURE.md §4·§14·§15

## 맥락
SOOP/위플랩 연동은 기능별 공식 접근 범위가 완전히 검증되지 않았다. 그럼에도 포트폴리오는 외부 API가 없어도 독립적으로 작동해야 한다.

## 결정
MVP는 관리자 수동 입력으로 `RewardAcquisitionEvent`에 근거한 `RewardGrant` 및 이행 상태를 관리한다. 외부 이벤트가 나중에 추가되더라도 공통 Application Use Case를 호출하고, 시스템별 변환은 Integration Adapter에서 수행한다. 외부 유입은 출처·외부 이벤트 ID를 기록하고 재시도 및 중복 수신을 처리한다.

## 검토한 대안
- 위플랩 실시간 자동 수집부터 구현: 접근 허용 여부와 프로토콜 변경에 제품 전체가 종속된다.
- 자체 룰렛 추첨 엔진 구축: 기존 방송 도구와 기능이 중복되고 MVP 목표를 벗어난다.

## 결과와 트레이드오프
초기에는 관리자 입력 부담이 있지만, 제품 완성·테스트·시연이 가능하다. 연동 가능성은 별도 기술 검증으로 추적한다.

## 재검토 조건
합법적·안정적인 연동 경로와 실사용 요구가 확인되면 외부 연동을 P1에 구현한다.
